# Snip2Pin 0.3.0

## 简体中文

截图，原位置顶。首个公开版本，支持 Windows、macOS 和 Linux。

- 拖动框选，或单击识别到的窗口截图；完成后自动复制并置顶。
- 使用系统拖动和边缘缩放，也支持滚轮、触摸板捏合及键盘微调；复制始终保留原图。
- 在主页定位、命名、锁定和拖动排序贴图；拖动列表时卡片跟随鼠标，原行留空。
- 自动适配多显示器，图内按钮避让屏幕边缘；锁定防止误操作，全局快捷键可解锁全部贴图。
- 中英文、浅深主题和图标默认跟随系统，均可手动选择；截图快捷键可修改，开机自启默认关闭。
- 提供菜单栏／托盘和 macOS Dock 菜单，以及可直接操作的[网页演示](https://snip2pin.github.io/Snip2Pin/)。

### 下载与安装

| 系统 | 安装包 |
| --- | --- |
| macOS 13+，Apple silicon | `aarch64-apple-darwin` DMG，打开后拖入 Applications |
| macOS 13+，Intel | `x86_64-apple-darwin` DMG，打开后拖入 Applications |
| Windows 10/11，x64 | `x86_64-pc-windows-msvc` Setup.exe 或便携 ZIP |
| Linux，x64 | `x86_64-unknown-linux-gnu` tar.gz；Ubuntu 24.04 可使用 .deb |

Linux 包基于 Ubuntu 24.04 / glibc 2.39，不保证旧发行版兼容。纯 Wayland 下的置顶、全局快捷键和绝对定位受桌面限制；需要这些能力时使用 X11/XWayland。中文界面需要系统中文字体。AUR 尚未发布。

截图只在用户操作时发生，图片保存在内存中，不上传、不保留历史。macOS 首次截图需按应用提示授予屏幕录制权限。

## English

Snip a region. Pin it in place. The first public release supports Windows, macOS and Linux.

- Drag a region or click a detected window to capture, copy and pin it.
- Use native dragging and edge resizing, wheel or trackpad pinch zoom, and keyboard adjustments. Copying always preserves the original pixels.
- Locate, name, lock and reorder pins on Home. Dragged list cards follow the pointer while their original row stays empty.
- Work across monitors with controls kept inside visible screen bounds. Lock pins against accidental changes and unlock all pins with the recovery shortcut.
- Chinese/English, light/dark themes and icons follow the system with manual overrides. The capture shortcut is customizable; login startup is off by default.
- Access actions from the menu bar / tray and macOS Dock, or try the interactive [web demo](https://snip2pin.github.io/Snip2Pin/).

### Download and install

| System | Package |
| --- | --- |
| macOS 13+, Apple silicon | `aarch64-apple-darwin` DMG; drag the app into Applications |
| macOS 13+, Intel | `x86_64-apple-darwin` DMG; drag the app into Applications |
| Windows 10/11, x64 | `x86_64-pc-windows-msvc` Setup.exe or portable ZIP |
| Linux, x64 | `x86_64-unknown-linux-gnu` tar.gz; .deb for Ubuntu 24.04 |

Linux packages target Ubuntu 24.04 / glibc 2.39; older distributions are not guaranteed. Pure Wayland restricts pinning, global shortcuts and absolute positioning; use X11/XWayland when these are needed. Chinese UI requires a system CJK font. No AUR package has been published yet.

Capture happens only on request. Images stay in memory, with no uploads or capture history. On macOS, follow the in-app screen-recording permission prompts on first capture.
