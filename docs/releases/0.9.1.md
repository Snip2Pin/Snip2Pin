# Snip2Pin 0.9.1

## 简体中文

- 修复 macOS 外接显示器重连后，截图高亮无法切换到另一屏幕的问题。
- macOS 显示器配置变化时退出当前截图，清除高亮并释放输入；下次截图重新读取屏幕布局。
- 修复 macOS 显示器变化后旧截图事件仍被接受，以及已有贴图按钮可能消失的问题。
- 独立的 macOS 开发版使用统一应用名和独立配置，避免与发行版身份冲突。
- 更新构建依赖和网页构建工具。

macOS 首次截图需要屏幕录制权限。Linux 包基于 Ubuntu 24.04 / glibc 2.39，建议使用 X11；Wayland 能力取决于桌面环境。Windows 原生 x64 性能、完整多屏覆盖及 KDE/Wayland 交互验收范围与 0.9.0 相同。

## English

- Fix macOS capture highlights failing to move between screens after reconnecting an external display.
- On macOS, exit capture when the display configuration changes, clearing highlights and releasing input. The next capture reads the current layout.
- Reject expired capture events and keep existing pin controls reachable after macOS display changes.
- Give macOS development installs a consistent app name and separate settings and identity.
- Update build dependencies and web build tooling.

macOS requires screen-recording permission on first capture. Linux packages target Ubuntu 24.04 / glibc 2.39; X11 is recommended and Wayland capabilities depend on the desktop. Native Windows x64 performance, full multi-monitor coverage and KDE/Wayland interaction acceptance retain the limitations of 0.9.0.
