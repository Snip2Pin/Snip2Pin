# Snip2Pin 0.9.0

## 简体中文

截图，原位置顶。Snip2Pin · 截图置顶的首个公开版本。

- 拖动框选，或单击识别到的窗口；截图后自动复制并置顶，不保留截图历史。
- 系统原生拖动与边缘缩放，支持滚轮、触摸板捏合和键盘微调；复制始终保留原图像素。
- 在主页定位、命名、锁定和拖动排序贴图，支持全局解锁快捷键。
- 自动识别多显示器；中英文、主题和图标默认跟随系统，也可手动选择。
- 自定义截图快捷键，开机自启默认关闭；菜单栏／托盘、macOS Dock 提供常用操作，帮助入口直达 Wiki。

## English

Snip a region. Pin it in place. The first public release of Snip2Pin.

- Drag a region or click a detected window to capture, copy and pin it. No capture history is stored.
- Use native dragging and edge resizing, wheel or trackpad pinch zoom, and keyboard adjustments. Copying always preserves the original pixels.
- Locate, name, lock and reorder pins on Home; unlock all pins with the recovery shortcut.
- Automatic monitor detection; Chinese/English, themes and icons follow the system with manual overrides.
- Customize the capture shortcut; login startup is off by default. Access actions from the menu bar / tray and macOS Dock, with Help opening the Wiki.

### Download and install

| System | Download |
| --- | --- |
| macOS 13+, Apple silicon | `aarch64-apple-darwin` DMG; drag into Applications |
| macOS 13+, Intel | `x86_64-apple-darwin` DMG; drag into Applications |
| Windows 10/11, x64 | `x86_64-pc-windows-msvc` Setup.exe or portable ZIP |
| Linux, x64 | `x86_64-unknown-linux-gnu` tar.gz; .deb for Ubuntu 24.04 |

Grant screen-recording permission on first capture in macOS. Linux packages target Ubuntu 24.04 / glibc 2.39; older distributions are not guaranteed. X11 is recommended. Pure Wayland restricts pinning, global shortcuts, window detection and absolute positioning; KDE/Wayland interaction acceptance is incomplete. Windows interaction tests used x64 emulation on ARM64 and do not establish native x64 performance or full multi-monitor coverage. Chinese UI requires a system CJK font. No AUR package has been published.
